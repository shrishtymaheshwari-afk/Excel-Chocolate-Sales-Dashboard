# Chocolate Sales Performance Dashboard | Microsoft Excel

An interactive Excel dashboard tracking chocolate sales performance, profitability, and salesperson KPIs across product categories (Dec 2021 – Dec 2022).

## Dashboard Preview
![Dashboard](dashboard_screenshot.png)

## Key KPIs
- Total Sales: $38,77,566
- Total Boxes Sold: 2,22,220
- Overall Profit %: 85.5%

## Dashboard Features
- Top 5 Products by Sales — 99% Dark & Pure leads
- Month-wise Sales, Boxes & Profit% trend
- Salesperson Performance Table with color indicators
- Category & Product-wise dynamic filters
